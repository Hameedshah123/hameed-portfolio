Enterprise Round-Robin Routing System

Critical infrastructure for a multi-million user account transfer

The Crisis

A major partner account transfer was scheduled involving millions of users. The existing manual assignment process would have required 20+ new hires and 3 months of onboarding. We had 3 weeks until go-live.

My Approach

  • Identified the scheduling infrastructure gap during a routine account review
  • Designed a weighted round-robin algorithm balancing capacity and expertise
  • Built the complete system in Python with REST API endpoints
  • Integrated with existing Salesforce and calendar systems
  • Added real-time monitoring and auto-rebalancing

Algorithm Design

  • Primary weight: Current load vs. max capacity (60%)
  • Secondary weight: Industry expertise match (25%)
  • Tertiary weight: Tenure/seniority score (15%)
  • Fallback: Overflow pool for surge capacity
  • Auto-rebalance every 4 hours based on completion rates

Impact

  • Delivered in 2.5 weeks (ahead of 3-week deadline)
  • 20+ hires avoided — $1.2M annual savings
  • Zero downtime during the multi-million user transfer
  • System still in production 18 months later

Tools Used

Python Flask Redis Salesforce API Google Calendar API Cron Datadog
Routing Algorithm
# Weighted Round-Robin with Load Balancing def calculate_score(rep, account): load_score = 1.0 - (rep.current_load / rep.max_capacity) expertise_score = rep.expertise.match(account.industry) tenure_score = rep.seniority_index / 10.0 return ( 0.60 * load_score + 0.25 * expertise_score + 0.15 * tenure_score ) # Auto-rebalance every 4 hours def rebalance_pool(team): overloaded = [r for r in team if r.load > 0.8] for rep in overloaded: redistribute_accounts(rep, team)

Create playbooks, style guides, and runbooks so teams can replicate and scale without me. Knowledge transfer is as important as the solution itself.
